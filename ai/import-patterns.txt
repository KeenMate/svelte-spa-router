MIGRATION FROM V3/V4
--------------------
Old (v3/v4):
import { params } from 'svelte-spa-router/stores'
$: userId = $params.id

New (v5):
import { routeParams } from '@keenmate/svelte-spa-router'
const params = $derived(routeParams())
const userId = $derived(params.id)

Or in component:
let { routeParams = {} } = $props()
const userId = $derived(routeParams.id)

TREE SHAKING
------------
Package.json includes:
"sideEffects": ["**/*.svelte", "**/*.svelte.js"]

Files with runes ($state, $derived) have side effects.
Prevents incorrect tree-shaking by bundlers.

BEST PRACTICES
--------------
- Import from main module when possible
- Use specific helper paths for advanced features
- Never import from /stores (doesn't exist)
- Use routeParams, not params
- Call functions (location()), don't use $ syntax
- Import only what you need
- Use TypeScript types for better DX
