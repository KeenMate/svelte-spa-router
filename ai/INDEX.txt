QUICK PROBLEM SOLVING
----------------------
Problem: "Missing './stores' specifier" error
→ import-patterns.txt (no /stores path exists, use main module)

Problem: "Route X not found in registry. Registered routes: []"
→ named-routes.txt (call registerRoutes() in main.js)
→ basic-setup.txt (ENABLING NAMED ROUTES section)

Problem: routeParams is undefined
→ import-patterns.txt (use routeParams not params)

Problem: $routeParams is not defined
→ import-patterns.txt (call as function, not store syntax)

Problem: Navigation not working
→ navigation.txt (check push/replace usage)
→ debug-logging.txt (enable ROUTER:NAVIGATION logs)

Problem: Route not matching
→ route-params.txt (check route pattern)
→ debug-logging.txt (enable ROUTER logs)

Problem: Permissions not checking
→ permissions.txt (check configurePermissions setup)
→ debug-logging.txt (enable ROUTER:PERMISSIONS logs)

Problem: Conditions not running
→ guards-conditions.txt (check wrap() usage)
→ debug-logging.txt (enable ROUTER:CONDITIONS logs)

Problem: User leaves page without confirmation (form changes lost)
→ navigation-guards.txt (registerBeforeLeave / PageWrapper / createDirtyCheckGuard)

Problem: beforeLeave not firing on browser tab close
→ navigation-guards.txt (attach isDirty function to enable beforeunload)

Problem: Scroll not restoring
→ referrer-tracking.txt (use goBack() not manual push)
→ basic-setup.txt (restoreScrollState prop)

Problem: Active link not highlighting
→ link-actions.txt (check use:active usage)
→ link-actions.txt (prefix matching for nested routes)

Problem: Breadcrumbs not inheriting
→ hierarchical-routes.txt (enable hierarchical mode)
→ breadcrumbs.txt (check inheritBreadcrumbs flag)

Problem: Back button not working
→ referrer-tracking.txt (setIncludeReferrer setup)
→ navigation.txt (goBack function)

Problem: Error not caught
→ error-handling.txt (GlobalErrorHandler setup)
→ error-handling.txt (check strategy configuration)

Problem: Query params not parsing
→ utilities.txt (use parse() function)

SVELTE 5 REMINDERS
------------------
CRITICAL: This router uses RUNES, not stores!

✅ CORRECT:
const path = $derived(location())
const params = $derived(routeParams())
let { routeParams = {} } = $props()

❌ WRONG:
const path = $location
const params = $routeParams
import from '@keenmate/svelte-spa-router/stores'
