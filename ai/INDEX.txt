FILE DESCRIPTIONS
-----------------
basic-setup.txt
  Foundation: Installation, hash/history modes, route definitions,
  Router props, event payload shapes including relativeLocation
  Start here for: Getting started, first-time setup

navigation.txt
  Navigation: push, replace, pop, goBack, navigation context (with
  null-when-empty contract), querystring in navigation
  Start here for: Programmatic navigation, passing data between routes

named-routes.txt
  Route naming: defineRoutes (recommended), registerRoutes (lower-level),
  buildUrl, hasRoute, getRouteByName
  Start here for: Type-safe routes, using route names instead of paths

route-params.txt
  Parameters: Route patterns, :params, wildcards, parameter access
  Start here for: Dynamic routes, extracting URL parameters

permissions.txt
  Security: Permission system, setCurrentUser-based reactivity,
  protected routes, authorization callbacks, revalidateCurrentRoute
  Start here for: Role-based access control, resource authorization,
  live permission updates

guards-conditions.txt
  Route protection: Guards, conditions, async checks, redirects,
  shouldDisplayLoadingOnRouteLoad + hideLoading contract
  Start here for: Authentication checks, conditional routing

navigation-guards.txt
  Exit guards: beforeLeave, PageWrapper, createDirtyCheckGuard,
  browser beforeunload
  Start here for: Unsaved-changes warnings, confirm-before-leave dialogs

hierarchical-routes.txt
  Inheritance: Hierarchical mode, breadcrumb/permission/condition
  inheritance
  Start here for: DRY route definitions with parent-child relationships

tree-structure.txt
  Nested definition: createHierarchy(), tree-style route definitions
  Start here for: Alternative syntax for deeply nested routes

link-actions.txt
  Links: link action, active highlighting, modifier key support
  Start here for: SPA links, navigation menus, active states

error-handling.txt
  Error recovery: GlobalErrorHandler (no built-in toast — use onError),
  recovery strategies (navigateSafe/restart/showError/custom), restart
  loop prevention, ignoreErrors filtering, ErrorDisplay component
  Start here for: Catching unhandled errors, user-friendly error pages

referrer-tracking.txt
  Back navigation: Referrer tracking, goBack(), scroll restoration
  Start here for: "Go Back" buttons, returning to previous route

debug-logging.txt
  Debugging: Category-based logging, enable/disable, runtime config
  Start here for: Troubleshooting routing issues

import-patterns.txt
  Imports: Correct import paths, common errors, migration guide
  Start here for: Import errors, upgrading from v3/v4

utilities.txt
  Helpers: joinPaths, stateless parseQuerystring/stringifyQuerystring,
  loc(), URL utilities. For the reactive query/filter API see
  querystring-filters.txt.
  Start here for: Low-level URL manipulation, manual query parsing

querystring-filters.txt
  Reactive querystring + filters: configureQuerystring + query(),
  configureFilters + filters() + updateFilters, flat vs structured
  (OData) mode, arrayFormat handling
  Start here for: URL-driven UIs, search/filter pages, OData APIs

route-metadata.txt
  Title, breadcrumbs, routeContext (reactive read), updateTitle/
  updateBreadcrumb/updateRouteMetadata (write), showLoading/hideLoading/
  routeIsLoading + shouldDisplayLoadingOnRouteLoad contract
  Start here for: Dynamic page titles, breadcrumb updates after data
  loads, three-pattern loading state management

breadcrumbs.txt
  Navigation trail: Breadcrumb definitions, dynamic updates. For the
  full route-metadata helper API, see route-metadata.txt.
  Start here for: Showing current location in site hierarchy

QUICK PROBLEM SOLVING
----------------------
Problem: "Missing './stores' specifier" error
→ import-patterns.txt (no /stores path exists, use main module)

Problem: "Route X not found in registry. Registered routes: []"
→ named-routes.txt (call defineRoutes or registerRoutes() in main.js)
→ basic-setup.txt (ENABLING NAMED ROUTES section)

Problem: routeParams is undefined
→ import-patterns.txt (use routeParams not params)

Problem: $routeParams is not defined
→ import-patterns.txt (call as function, not store syntax)

Problem: hasPermission doesn't update in {#if} when permissions change
→ permissions.txt (use setCurrentUser, avoid get(store) footgun)

Problem: User on protected page when permissions are revoked
→ permissions.txt (call revalidateCurrentRoute after permission change)

Problem: navigationContext() is never null after push
→ navigation.txt (fixed in v5.2.0-rc02 — _routeName now filtered)

Problem: push('/path', {}, queryObj) drops the query
→ Fixed in v5.2.0-rc02. Upgrade if you're on rc01 or earlier.

Problem: onNotFound never fires (despite catch-all '*' route)
→ Fixed in v5.2.0-rc02. Upgrade if you're on rc01 or earlier.
→ basic-setup.txt (EVENT PAYLOAD SHAPE)

Problem: Loading screen stays up forever
→ route-metadata.txt (shouldDisplayLoadingOnRouteLoad requires
  hideLoading() — check your onMount completes that call)
→ guards-conditions.txt (same — see the contract callout)

Problem: Navigation not working
→ navigation.txt (check push/replace usage)
→ debug-logging.txt (enable ROUTER:NAVIGATION logs)

Problem: Route not matching
→ route-params.txt (check route pattern)
→ debug-logging.txt (enable ROUTER logs)

Problem: Permissions not checking
→ permissions.txt (check configurePermissions + setCurrentUser)
→ debug-logging.txt (enable ROUTER:PERMISSIONS logs)

Problem: Conditions not running
→ guards-conditions.txt (check wrap() / createRoute() usage)
→ debug-logging.txt (enable ROUTER:CONDITIONS logs)

Problem: User leaves page without confirmation (form changes lost)
→ navigation-guards.txt (registerBeforeLeave / PageWrapper / createDirtyCheckGuard)

Problem: beforeLeave not firing on browser tab close
→ navigation-guards.txt (attach isDirty function to enable beforeunload)

Problem: Scroll not restoring
→ referrer-tracking.txt (use goBack() not manual push)
→ basic-setup.txt (restoreScrollState prop)

Problem: Active link not highlighting
→ link-actions.txt (check use:active usage, prefix matching)

Problem: Breadcrumbs not inheriting
→ hierarchical-routes.txt (enable hierarchical mode)
→ route-metadata.txt (breadcrumb API)

Problem: Back button not working
→ referrer-tracking.txt (setIncludeReferrer setup)
→ navigation.txt (goBack function)

Problem: Error not caught
→ error-handling.txt (GlobalErrorHandler setup, check strategy)

Problem: Error toast not appearing
→ error-handling.txt (built-in toast removed in rc02 — wire your own
  via onError callback)

Problem: Query params not parsing
→ utilities.txt (parseQuerystring function)
→ querystring-filters.txt (reactive query() accessor)

SVELTE 5 REMINDERS
------------------
CRITICAL: This router uses RUNES, not stores!

✅ CORRECT:
const path = $derived(location())
const params = $derived(routeParams())
let { routeParams = {} } = $props()

❌ WRONG:
const path = $location
const params = $routeParams
import from '@keenmate/svelte-spa-router/stores'
