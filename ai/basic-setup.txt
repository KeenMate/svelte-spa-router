BASIC ROUTER SETUP
==================

CRITICAL: This is Svelte 5 router using RUNES, NOT stores
- Use $state(), $derived(), $effect()
- NO writable(), readable(), derived()
- NO $: reactive declarations
- NO $store syntax

HASH MODE (default)
-------------------
URLs: http://example.com/#/path
No server config needed

// main.js
import { mount } from 'svelte'
import App from './App.svelte'

mount(App, { target: document.getElementById('app') })

// App.svelte
<script>
import Router from '@keenmate/svelte-spa-router'
import Home from './Home.svelte'
import About from './About.svelte'
import NotFound from './NotFound.svelte'

const routes = {
    '/': Home,
    '/about': About,
    '/user/:id': UserProfile,
    '/books/*': BookWildcard,
    '*': NotFound  // Must be last
}
</script>

<Router {routes} />

HISTORY MODE (clean URLs)
--------------------------
URLs: http://example.com/path
Requires server fallback to index.html

// main.js
import { mount } from 'svelte'
import { setHashRoutingEnabled, setBasePath } from '@keenmate/svelte-spa-router'
import App from './App.svelte'

setHashRoutingEnabled(false)
setBasePath('/')  // Or '/app' for subdirectory

mount(App, { target: document.getElementById('app') })

// App.svelte - same as hash mode

SERVER CONFIG
-------------
History mode requires server fallback:

// Vite (vite.config.js)
export default {
    server: {
        historyApiFallback: true
    }
}

// Express
app.get('*', (req, res) => {
    res.sendFile(path.join(__dirname, 'index.html'))
})

// Nginx
location / {
    try_files $uri $uri/ /index.html;
}

ROUTE DEFINITION PATTERNS
--------------------------
Flat object:
const routes = {
    '/': Home,
    '/about': About,
    '*': NotFound
}

Map (for non-standard paths):
const routes = new Map([
    ['/', Home],
    ['/about', About],
    ['*', NotFound]
])

ROUTER PROPS
------------
<Router
    {routes}
    prefix="/app"                                  // For nested routers
    restoreScrollState={true}                      // Default: true
    onRouteLoading={(e) => console.log(e.detail)}  // Route starting
    onRouteLoaded={(e) => console.log(e.detail)}   // Route loaded
    onConditionsFailed={(e) => push('/unauthorized')}
    onNotFound={(e) => console.log('404:', e.detail)}
/>

EVENT PAYLOAD SHAPE (e.detail)
-------------------------------
onRouteLoading:
    { route, location, relativeLocation, querystring, params }
    Fires before guards/conditions run for a matched route.

onRouteLoaded:
    { route, location, relativeLocation, querystring, params,
      component?, name?, routeContext?, zones? }
    Fires after the matched component (and any async children) mounts.
    zones is set for multi-zone routes; component/name/routeContext for
    single-component routes.

onConditionsFailed:
    { route, location, relativeLocation, querystring, params }
    A condition in wrap({ conditions }) returned false. The slot is now
    empty — handle the redirect here or inside the condition itself.

onNotFound:
    { location, relativeLocation, querystring }
    Fires when no route matched OR when the '*' catch-all matched. (Prior
    to v5.2.0-rc02, this event was suppressed if '*' was configured — now
    it always fires, so consumers can log every 404 regardless of whether
    the catch-all is present.)

LOCATION VS RELATIVELOCATION
-----------------------------
location           Full app URL the browser sees (e.g. /test/embed/missing).
                   Use for logging, analytics, push() (always app-wide).
relativeLocation   The path with the Router's prefix stripped (e.g.
                   /missing for a <Router prefix="/test/embed" />). Use
                   when reasoning about what THIS Router instance saw —
                   matches how routes inside it were defined.
                   For a root Router with no prefix, the two are equal.

ROUTE COMPONENT PROPS
---------------------
Route components receive:

<script>
// Child component (e.g., UserProfile.svelte)
let { routeParams = {} } = $props()
</script>

<p>User ID: {routeParams.id}</p>

ACCESSING ROUTE STATE
----------------------
Import from main module or /utils:

import { location, querystring, routeParams, navigationContext } from '@keenmate/svelte-spa-router'

// Use as FUNCTIONS (not stores!)
const path = $derived(location())
const query = $derived(querystring())
const params = $derived(routeParams())
const navContext = $derived(navigationContext())

CONFIGURATION OPTIONS
---------------------
// main.js - configure before mount
import {
    setHashRoutingEnabled,
    setBasePath,
    setParamReplacementPlaceholder,
    setIncludeReferrer
} from '@keenmate/svelte-spa-router'

setHashRoutingEnabled(false)           // Enable history mode
setBasePath('/app')                    // Base path for subdirectory
setParamReplacementPlaceholder('N-A')  // Placeholder for missing params
setIncludeReferrer('always')           // Track referrer: 'never', 'notfound', 'always'

ENABLING NAMED ROUTES
---------------------
Named route navigation (push('routeName', params)) requires registration.
Use defineRoutes() (recommended) — it auto-registers names AND gives you
type-safe nav.X.push / paths.X helpers:

// routes.js
import { defineRoutes } from '@keenmate/svelte-spa-router/routes'

const { routes, nav, paths } = defineRoutes({
    home: { path: '/', component: Home },
    userProfile: { path: '/user/:userId', component: UserProfile }
})

export { routes, nav, paths }

// main.js
import { routes } from './routes'
// no separate registerRoutes() call needed

// Now you can navigate by name:
await push('userProfile', { userId: 123 })  // → /user/123
// Or with the typed helper:
nav.userProfile.push({ userId: 123 })

Lower-level API — registerRoutes():

import { registerRoutes } from '@keenmate/svelte-spa-router/routes'

registerRoutes({
    'home': '/',
    'userProfile': '/user/:userId',
    'documentDetail': '/documents/:docId'
})

See named-routes.txt for the full named routes API.

ERROR: "Route X not found in registry. Registered routes: []"
- defineRoutes() / registerRoutes() was never called
- Make sure your routes module is imported before navigation runs
